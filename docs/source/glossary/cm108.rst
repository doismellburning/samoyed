CM108
=====

.. ai-label:: generated

A family of cheap USB audio chips
(CM108, CM119 and compatibles)
whose spare GPIO pins can key a transmitter.
Many radio interfaces are built around one,
so a single USB connection gives both audio and :doc:`ptt`.
