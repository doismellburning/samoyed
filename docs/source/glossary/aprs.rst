APRS
====

🤖 The Automatic Packet Reporting System:
positions, messages, objects, weather and telemetry
sent as :doc:`ax25` UI frames,
spread by :doc:`digipeaters <digipeater>`
and gatewayed to the internet (APRS-IS) by :doc:`IGates <igate>`.

----------

* `The APRS Documentation Project <https://github.com/wb2osz/aprsspec>`__ - collected specifications, including ``APRS101.pdf``, ``Understanding-APRS-Packets.pdf`` and ``APRS-Digipeater-Algorithm.pdf``
* `APRS-IS <https://www.aprs-is.net/>`__
* `APRS on Wikipedia <https://en.wikipedia.org/wiki/Automatic_Packet_Reporting_System>`__
