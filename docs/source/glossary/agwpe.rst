AGWPE
=====

🤖 The TCP application interface of SV2AGW's AGW Packet Engine.
A client application connects
and exchanges frames
to send and monitor :doc:`ax25` traffic
and to open connected-mode sessions without implementing the link layer itself.
It does more than :doc:`kiss`, at the cost of being a larger protocol.
