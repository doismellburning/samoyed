IGate
=====

.. ai-label:: generated

An internet gateway for :doc:`aprs`:
a station that passes packets it hears on air to APRS-IS,
the internet backbone of APRS,
and can pass selected traffic,
such as messages for stations it has heard recently,
back to air.
A ``q`` construct added to the path records how a packet reached APRS-IS.
