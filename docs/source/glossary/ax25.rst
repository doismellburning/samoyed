AX.25
=====

.. ai-label:: generated

The link-layer protocol of packet radio:
:doc:`hdlc` frames addressed by callsign and SSID,
with an optional path of :doc:`digipeaters <digipeater>`.
It has connectionless (UI) frames, which :doc:`aprs` uses,
and a connected mode with acknowledgements and retries.
:doc:`fx25` and :doc:`il2p` add forward error correction on air.
