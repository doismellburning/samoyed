FX.25
=====

.. ai-label:: generated

Forward error correction for :doc:`ax25`:
the usual :doc:`hdlc` frame is wrapped in a Reed-Solomon code block,
preceded by a correlation tag that says which code was used.
A receiver that knows FX.25 can repair damaged bits;
one that doesn't still finds the ordinary frame inside
and decodes it as before.
